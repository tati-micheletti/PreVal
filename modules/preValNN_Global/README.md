# preValNN_Global

Per species: network settings by a pilot on the pre-test history only, covariate ranking by permutation importance (correlated
covariates permuted together; random and forward modes), effective number of covariates, spatial block size from the residual
autocorrelation. Uses the engine in `modules/preValNN/R` (sourced, not duplicated). See `birds/ANALYSIS_PLAN_BIRDS.md`.
